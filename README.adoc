== Accessing files (5 points)

Create a script `part-1.sh` which downloads a bash script from the server and runs it.

The server is running on `server`. You can connect to it using the FTP protocol.

The file you need is accessible through the endpoint `java/kotlin/groovy.sh`.

Credentials are passed as env variables: `USER` & `PASSWORD`.

CAUTION: Your script must not pollute the filesystem!

=== Error handling

Is not needed. We guarantee the correctness of the input data.

== Uploading files (5 points)

Create a script `part-2.sh` which uploads a file to the server.

The server is running on `server`. You can connect to it using the FTP protocol.

The file you need is passed as `$1`.

After the file is uploaded, it must be accessible through the endpoint `/sieben/ein/zwei.drei`.

Credentials are passed as env variables: `USER` & `PASSWORD`.

CAUTION: Your script must not pollute the filesystem!
